System Architecture

Everything runs on one laptop — the cloud was only used to build the AI · SIF-Precursor Engine · SIH 26165

No internet needed at runtime

  • • Website, AI models and database all on one laptop
  • • Works in plants and sites with no connectivity
  • • Every real report stays on-site, always
  • • No accounts, no subscriptions, no uploads

What the cloud was for

  • • Kaggle's free GPUs trained the model once
  • • Only public or AI-written data was used
  • • Just the trained model file came back
  • • The cloud never sees a real safety report

The pieces, in plain words

  • • SQLite — the whole database is one file
  • • Ollama — runs the local LLM on the laptop
  • • MiniLM — spots duplicate reports
  • • ONNX — a format that runs anywhere, fast
